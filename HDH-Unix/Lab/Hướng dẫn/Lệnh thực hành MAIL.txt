Lệnh thực hành MAIL

Cấu hình dịch vụ DNS cho Mail service

Cài đặt gói postfix, dovecot, telnet:
	yum install postfix -y
	yum install dovecot -y
	yum install telnet -y

Cấu hình dịch vụ Mail:
	Mở file cấu hình DNS: gedit /etc/named.conf
		Thêm nội dung vào mục options trong file, chỉ thêm vào các máy Client của DNS server, ko thêm vào server DNS:
			forwarders: { 8.8.8.8; };
		Nếu là DNS Server:
			Chứa zone (Tên miền) của tất cả các zone khác:
		Nếu là DNS Client:
			Chỉ chứa zone của client
		Mẫu zone:
			zone "<tên miền>.<đuôi>" IN {
				type master;
				file "<tên miền>.<đuôi>";
			};
	Mở file cấu hình Postfix: gedit /etc/postfix/main.cf
	Sửa nội dung:
		myhostname = mail.<Tên miền>.<Đuôi>
		mydomain = <Tên miền>.<Đuôi>

		myorigin = $mydomain

		inet_interfaces = all

		mydestination = $myhostname, localhost.$mydomain, localhost, $mydomain

		mynetworks = 127.0.0.0/8, <3 số đầu của địa chỉ DNS Server>.0/24 (Ví dụ: DNS Server ip 192.168.1.1 => 192.168.1.0)

		home_mailbox = Maildir/


		smtpd_sasl_auth_enable = yes
		smtpd_sasl_type = dovecot
		smtpd_sasl_path = private/auth
		smtpd_sasl_security_options = noanonymous
		broken_sasl_auth_clients = yes
	
Cấu hình Dovecot:
	Mở file: gedit /etc/dovecot/conf.d/10-master.conf
	Thay thế dòng 89 đến hết dòng 93 bằng:
		 unix_listener /var/spool/postfix/private/auth {
			mode = 0660
			user = postfix
			group = postfix
		}
	Mở file: gedit /etc/dovecot/conf.d/10-mail.conf
	Thêm vào dòng 31 nội dung sau:
		mail_location = maildir:~/Maildir
		
Mở cổng tường lửa:
	firewall-cmd --permanent --add-port=25/tcp
	firewall-cmd --permanent --add-port=110/tcp
	firewall-cmd --permanent --add-port=53/udp
	firewall-cmd --reload
	setenforce 0
		
Chạy dịch vụ Mail:
	systemctl start named
	systemctl start postfix
	systemctl start dovecot
